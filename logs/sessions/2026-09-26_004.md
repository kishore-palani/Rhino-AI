### 3.2 Module 1: `ai/memory/skill_memory.py`

**Purpose:** Track every skill execution with full context

**Key Classes:**
- `SkillExecution` — Dataclass representing a single execution record
  - skill_id, parameters, success, execution_time_ms
  - preconditions, geometry_ids, validation_issues
  - error, plan_context, timestamp

- `SkillMemory` — Execution history manager
  - `record_execution()` — Store to in-memory + AgentMemory
  - `get_success_rate()` — Calculate success rate per skill
  - `get_parameter_ranges()` — Successful vs failed parameter distributions
  - `query_similar()` — Find executions with similar parameters

**Statistics:**
- ~160 lines of code
- 15 unit tests (all passing)

### 3.3 Module 2: `ai/memory/failure_patterns.py`

**Purpose:** Detect recurring failures and suggest fixes

**Key Classes:**
- `FailurePattern` — Recognized recurring failure mode
  - pattern_id, failure_type, description
  - occurrences, common_attributes, suggested_fix
  - confidence, first_seen, last_seen

- `FailurePatternRecognizer` — Pattern analyzer
  - `record_failure()` — Ingest failure, update or create pattern
  - `get_patterns()` — Retrieve patterns by type and frequency
  - `suggest_correction_for()` — Lookup fix for failure context
  - `_deduce_fix()` — Auto-generate common corrections

**Failure Types:**
- Dimensional (wall too thin, height clearance)
- Geometric (open solids, naked edges, non-manifold)
- Regulatory (code violations)
- MCP (connection, slot issues)
- Skill (execution failures)

**Auto-Fix Examples:**
- "Wall thickness <150mm" → "Ensure wall thickness is at least 150mm"
- "Open solid" → "Ensure boundary curves are closed and planar"
- "MCP slot error" → "Ensure fresh Rhino slot is spawned"

**Statistics:**
- ~160 lines of code
- 8 unit tests (all passing)

### 3.4 Module 3: `ai/memory/feedback_analysis.py`

**Purpose:** Parse and structure natural-language user feedback

**Key Classes:**
- `FeedbackRecord` — Structured feedback representation
  - feedback_id, original_request, user_feedback
  - feedback_type, extracted_corrections
  - affected_elements, action_taken, timestamp

- `FeedbackAnalyzer` — NL feedback parser
  - `parse_feedback()` — Convert NL → structured record
  - `_classify_feedback_type()` — Categorize by domain
  - `_extract_parameters()` — Extract dimensions and directives
  - `_extract_affected_elements()` — Identify target components

**Feedback Categories:**
1. **Dimensional:** "make it 2.7m taller", "reduce thickness to 200mm"
2. **Functional:** "bedroom should not open to entrance for privacy"
3. **Stylistic:** "facade is too heavy, make panels more subtle"
4. **Structural:** "add column to support the beam"
5. **General:** Other feedback

**Parameter Extraction:**
- Explicit dimensions: `2.7m`, `200mm`, `5000mm`
- Relative changes: `wider`, `taller`, `thinner`, `narrower`
- Target elements: `wall`, `door`, `window`, `column`, etc.

**Statistics:**
- ~180 lines of code
- 8 unit tests (all passing)
- Fixed classification logic to prioritize specific categories over generic keywords

### 3.5 Module 4: `ai/memory/query.py`

**Purpose:** Unified interface for planner and executor to query all memory

**Key Classes:**
- `MemoryInsights` — Aggregated pre-planning insights
  - relevant_failures, known_patterns, user_preferences
  - successful_examples, warnings, suggestions

- `SkillInsights` — Execution-specific recommendations
  - skill_id, success_rate, known_failure_modes
  - suggested_parameter_ranges, warnings

- `CorrectionSuggestions` — Failure recovery recommendations
  - similar_failures, pattern_based_fixes
  - related_feedback, recommendations

- `MemoryQuery` — Unified query API
  - `query_before_plan()` — Pre-planning memory aggregation
  - `query_before_skill_execution()` — Parameter validity checks
  - `query_for_correction()` — Failure recovery suggestions

**Integration Points:**
- Planner calls `query_before_plan()` before generating modeling plans
- Executor calls `query_before_skill_execution()` before each skill
- Validator calls `query_for_correction()` on validation failures
